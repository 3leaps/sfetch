# sfetch v0.4.13

Maintenance release for verified development bootstrap and draft-preserving
release uploads.

## Highlights

### Verified bootstrap

- The Makefile N-1 self-bootstrap and CI install-smoke pin advances from
  v0.4.11 to the fully signed v0.4.12 release.
- Fresh isolated bootstrap verification selects the minisign route and current
  release trust anchor for v0.4.12.
- The bootstrap engine accepts v0.4.13 as its committed ceiling. Historical
  v0.4.11 previous-key and v0.4.10 checksum-route coverage remains unchanged.

### Draft-preserving release uploads

- Every `softprops/action-gh-release` step explicitly declares `draft: true`,
  including all release-matrix archive uploads.
- A regression wired into `make precommit` enumerates those release-writing
  steps and rejects omitted or false draft settings.
- Tag CI remains non-consumable until the maintainer completes the attended
  sign, verify, upload, and explicit publish sequence.

## Compatibility

There are no CLI, dependency, supported-platform, self-update, or trust-anchor
changes. Existing consumers require no migration.
