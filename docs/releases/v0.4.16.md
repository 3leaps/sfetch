# sfetch v0.4.16

Download and install fixes: large release assets no longer time out, raw
release binaries install under the binary name with the executable bit, and
self-update verifies only against the minisign key embedded in sfetch.

## Highlights

**Large downloads**
- The 30-second whole-request timeout no longer limits reading the response
  body. Connection setup, TLS handshake, and response headers stay bounded at
  30 seconds each.
- A response body, including a redirect body, fails if no data arrives for
  60 seconds.

**Raw release binaries**
- A raw asset such as `tool-v1.2.3-macos-aarch64` installs as `tool`
  (`tool.exe` on Windows). The name defaults to the repo name;
  `--binary-name` overrides it.
- Names with dotted versions are recognized as executables and installed with
  the executable bit on macOS and Linux.
- Scripts, shared libraries (including versioned names such as `libfoo.so.1`),
  and non-executable files keep their asset names. `--url` and `--github-raw`
  keep the file name unless `--binary-name` is set.

**Key auto-detection**
- When no minisign key name pattern matches, a release's only `.pub` asset
  is used. Several unmatched `.pub` assets select none.

**Self-update**
- `--self-update` verifies against the minisign public key embedded in the
  sfetch binary, never a key published in the release.
- Key flags and the verification skips (`--insecure`, `--skip-sig`,
  `--skip-checksum`) are refused with `--self-update`.

**Development tooling**
- The verified bootstrap ceiling advances to `v0.4.16`; self-bootstrap and CI
  install smoke advance to the published, signed `v0.4.15` release.
- CI and the Makefile use goneat v0.6.8. A reviewed govulncheck waiver for
  GO-2026-5932 is recorded in `.goneat/dependencies.yaml`: the finding is
  module-level only, sfetch imports no `golang.org/x/crypto/openpgp` package,
  and the waiver expires 2027-02-10.
- Go 1.26.10 and the application dependency versions are unchanged from
  v0.4.15.

## Compatibility

Raw release binaries now install under the binary name instead of the asset
name. Pass `--binary-name` to choose a different name. `--url` and
`--github-raw` downloads are unchanged unless `--binary-name` is set.

`--self-update` no longer accepts key flags or verification skips. The
version doing the update runs the verification, so the embedded-key rule
applies to updates performed by v0.4.16 and later.

The five supported platforms and consumer verification trust anchors are
unchanged. Pair `sfetch-version: v0.4.16` with an immutable action revision
whose declared bootstrap range includes that tag.
